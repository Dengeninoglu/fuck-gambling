Option A · Block gambling only

Uses a free NextDNS account (3 minutes). Nothing except gambling is blocked.

  1. Open my.nextdns.io/signup and create a free account.
  2. Open the Parental Control tab → Categories → Add a category → Gambling.
  3. Open the Setup tab. Copy the address shown under DNS-over-TLS/QUIC (it looks like abc123.dns.nextdns.io).
  4. Phone Settings → search Private DNS → Private DNS provider hostname → paste → Save.

Give the NextDNS password to someone you trust, so the settings can't be changed in a weak moment. The free plan includes 300,000 lookups a month, which is enough for most phones.
